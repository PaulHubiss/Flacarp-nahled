# Flacarp-nahled

Veřejný repozitář jen pro **GitHub Pages**: zašifrovaný náhled 3D prezentace z projektu `../Flacarp`
pro kolegy (heslo). **Nic tu neupravuj** – `index.html` přepisuje `npm run zverejnit` ve Flacarpu
(`Flacarp/tools/zverejnit.mjs`). Heslo je jen v `Flacarp/.heslo-nahled` (mimo git).

Adresa: https://paulhubiss.github.io/Flacarp-nahled/
